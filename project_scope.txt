## PHASE 6: ONBOARDING & PRIVACY

### First-Time User Flow
```
1. Welcome screen explaining what the app does
2. Privacy notice (CRITICAL):
   - Screenshots are DELETED immediately after analysis
   - Data stored ONLY locally on your device
   - Nothing sent to any server except Gemini API
   - No cloud sync, no accounts, no tracking
3. API key setup (Gemini)
4. Email setup (optional)
5. Goal selection (productivity/learning/custom)
6. Start tracking
```

### Privacy Guarantees (must be visible)
- Screenshots deleted within 5 seconds of capture
- Database is local SQLite (user controls the file)
- No telemetry, no analytics, no phone home
- Open source (users can verify)
- Data export available (own your data)

### Config: Add privacy settings
```yaml
privacy:
  delete_screenshots_immediately: true  # Cannot be changed
  local_only: true                      # No cloud features
  show_privacy_reminder: true           # Startup reminder
```
