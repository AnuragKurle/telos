# ⚠️ Quick Setup Required

Your `config.yaml` has been created from the example, but you need to add your Gemini API key!

## Add Your API Key

**Option 1: Use the setup wizard (recommended)**
```bash
python main.py setup
```

**Option 2: Edit config.yaml manually**
```bash
# Edit client/config.yaml
# Add your API key to the gemini.api_key field
```

**Get your API key:** https://aistudio.google.com/app/apikey

---

Once configured, run:
```bash
python main.py
```

Enjoy! 🚀
