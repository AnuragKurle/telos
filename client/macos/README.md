# macOS Build Resources

This directory contains macOS-specific build resources for Telos.

## Files

- **dev.telos.tracker.plist** - LaunchAgent template for background service
- **icon.icns** - macOS application icon (to be created)
- **Info.plist** - App bundle metadata (auto-generated by PyInstaller)
- **entitlements.plist** - macOS permissions/entitlements (optional, for code signing)

## Icon Creation

To create the icon.icns file:

### Option 1: Using iconutil (macOS built-in)

1. Create a directory called `icon.iconset`
2. Add PNG images at these sizes:
   - icon_16x16.png
   - icon_16x16@2x.png (32x32)
   - icon_32x32.png
   - icon_32x32@2x.png (64x64)
   - icon_128x128.png
   - icon_128x128@2x.png (256x256)
   - icon_256x256.png
   - icon_256x256@2x.png (512x512)
   - icon_512x512.png
   - icon_512x512@2x.png (1024x1024)

3. Run: `iconutil -c icns icon.iconset`
4. Move the generated `icon.icns` to this directory

### Option 2: Using online converter

1. Create a high-resolution PNG (1024x1024 recommended)
2. Use an online converter like https://cloudconvert.com/png-to-icns
3. Download and place the `.icns` file in this directory

### Option 3: Using img2icns (if installed)

```bash
img2icns your-icon.png icon.icns
```

## LaunchAgent

The `dev.telos.tracker.plist` file is a template that will be:
- Copied to `~/Library/LaunchAgents/` during installation
- Modified with actual executable paths
- Loaded/unloaded by `service_macos.py`

To manually install/test:
```bash
cp dev.telos.tracker.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/dev.telos.tracker.plist
launchctl list | grep telos
```

To manually uninstall:
```bash
launchctl unload ~/Library/LaunchAgents/dev.telos.tracker.plist
rm ~/Library/LaunchAgents/dev.telos.tracker.plist
```

## Permissions

macOS requires explicit permissions for:

1. **Screen Recording** - Required for screenshot capture
   - System Preferences → Security & Privacy → Privacy → Screen Recording
   
2. **Accessibility** - Required for keyboard/mouse monitoring
   - System Preferences → Security & Privacy → Privacy → Accessibility

These permissions are requested via the Info.plist keys:
- `NSScreenCaptureUsageDescription`
- `NSAccessibilityUsageDescription`

## Code Signing (Optional)

For distribution outside the App Store, you can sign the app:

```bash
codesign --force --deep --sign "Developer ID Application: Your Name" Telos.app
```

For notarization (required for macOS 10.15+):
```bash
xcrun altool --notarize-app \
  --primary-bundle-id "dev.telos.tracker" \
  --username "your@email.com" \
  --password "@keychain:AC_PASSWORD" \
  --file Telos-v0.1.0-beta.dmg
```

Note: Code signing requires an Apple Developer account ($99/year).
