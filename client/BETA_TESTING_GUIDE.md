# Telos Beta Testing Guide

## 🎯 For Beta Testers (Non-Technical Users)

### What is Telos?
Telos is an AI-powered productivity tracker that runs quietly in the background, helping you understand how you spend your time on your computer.

---

## 📥 Installation (Super Simple)

### Step 1: Download
You'll receive a file named: **`Telos-v0.1.0-beta-Windows.zip`**

### Step 2: Extract
- Right-click the .zip file
- Select "Extract All..."
- Choose a location (e.g., Desktop or Downloads)

### Step 3: Launch
- Find `Telos.exe` in the extracted folder
- Double-click to run

### Step 4: Security Warning (First Time Only)
Windows will show a "Windows protected your PC" warning:
1. Click **"More info"**
2. Click **"Run anyway"**

**Why?** This is normal for new apps that don't have an expensive security certificate yet. The app is safe!

### Step 5: Follow Setup Wizard
The app will guide you through:
- Privacy notice
- Email setup (optional)
- Your productivity goals
- Quick tutorial

**That's it!** The app now runs in the background.

## 🖥️ Using Telos

### Accessing the Dashboard
- Look for the Telos icon in your **system tray** (bottom-right corner, near the clock)
- Click the icon to open the dashboard

### What You'll See
- **Today's Activity**: What you've been working on
- **Productivity Stats**: Work vs. browsing vs. entertainment
- **Timeline**: Hour-by-hour breakdown
- **Insights**: AI-powered observations about your work patterns

### Daily Reports
- If you enabled email reports, you'll receive a summary every evening
- Shows your most productive hours, main activities, and focus time

## ❓ Common Questions

### Does it record everything I do?
No! Telos:
- ✅ Analyzes window titles and app names
- ✅ Takes occasional screenshots for AI analysis (processed locally)
- ❌ Does NOT record keystrokes
- ❌ Does NOT store your screenshots
- ❌ Does NOT send personal data to the cloud

### Will it slow down my computer?
No! Telos is designed to be lightweight:
- Uses less than 100MB RAM
- Minimal CPU usage
- Smart scheduling (only analyzes when you're idle)

### Can I pause tracking?
Yes! Click the system tray icon → "Pause Tracking"

### Where is my data stored?
- Locally on your computer: `%APPDATA%\Telos\`
- Only anonymized analytics are sent to our servers
- You can delete all data anytime

### How do I uninstall?
1. Close Telos (right-click system tray → Exit)
2. Delete the `Telos.exe` file
3. (Optional) Delete data folder: `%APPDATA%\Telos\`

## 🐛 Troubleshooting

### App won't start
1. Make sure you clicked "Run anyway" on the security warning
2. Check if Windows Defender blocked it:
   - Open Windows Security
   - Go to "Virus & threat protection"
   - Check "Protection history"
   - If Telos is blocked, allow it

### Antivirus flagged it
Some antivirus software may flag new apps:
1. Add Telos.exe to your antivirus exclusions
2. Or temporarily disable antivirus during first launch

### Can't find the system tray icon
1. Click the ^ arrow in the system tray
2. Look for the Telos icon
3. Drag it to the main tray area for easy access

### App crashed or froze
1. Press Ctrl+Alt+Delete → Task Manager
2. Find "Telos" and end the task
3. Check logs: `%APPDATA%\Telos\logs\latest.log`
4. Send the log file to me for debugging

### No data showing up
1. Make sure the app has been running for at least 10 minutes
2. Try switching between different apps/windows
3. Check if tracking is paused (system tray icon should be green)
